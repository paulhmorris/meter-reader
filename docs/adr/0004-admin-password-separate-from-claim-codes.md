# Admin authenticates by password, not by a Claim Code

The Admin surface lists every Meter the SDR has heard, which is exactly the roster ADR-0001 refuses to publish, and it issues and rotates the Claim Codes the rest of the app trusts. So it is reached by a single password held only by the operator, kept in `ADMIN_PASSWORD` and exchanged for a separate signed cookie that expires after a week — no Claim Code, however lucky the guess, ever reaches it. Signing in is rate-limited per client address like a Claim, and the cookie carries the purpose it was signed for, so a Grant cookie cannot be replayed as an Admin session. The cost is a shared secret with no rotation story beyond editing the environment and restarting, which is proportionate to one operator running one radio.
